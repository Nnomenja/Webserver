Multipart Lab

Outil web pour tester ton serveur HTTP upload avec des requetes POST multipart/form-data, sans utiliser curl ou nc. Tu peux charger des fichiers, envoyer des champs texte, ajouter un bloc JSON, et voir un exemple de requete HTTP brute.

Exemples multipart inclus

  1. Texte simple: champs title + description sans fichier.
  2. Single file: un fichier principal + champ meta.
  3. Multiple files: plusieurs fichiers dans le meme champ files[].
  4. Mix JSON + fichier: payload JSON (Blob) + fichier binaire.
  5. Avatar + tags: fichier image et liste de tags repetes.

Ce site est ideal pour verifier le parsing multipart, la validation des limites upload, la gestion des erreurs 4xx/5xx, et les headers de reponse.
